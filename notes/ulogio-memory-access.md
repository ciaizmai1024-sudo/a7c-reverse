# ulogio 内存读写：地址模型与安全边界（上机前必读）

> 全文报告：`notes/ulogio-mem-fullreport.md`（MacBook 子代理 `ulogio-mem`）。下面是我筛过、与上机操作直接相关的部分。

## 1. 这些子命令读的是**物理地址**，而且**没有任何护栏**
- `db/dw/dl/dk`、`mb/mw/ml/mf/mu` 都由 CLI 自己打开 `/dev/mem` 类设备并 `mmap`，**mmap 的 offset 就是 PA**，`pagebase = addr & ~0xfff`。
- **没有白名单、没有窗口限制、不需要先 `switch` 进子系统**；掩码只用于对齐判断。只有 `logaddr [SID][SA]` 会在服务端查表校验 SID/area。
- **打到无效 PA 的后果是进程/整机挂死，不是报错。** ⇒ 上机只读我们已确证有效的窗口，别随手读。

## 2. 地址空间（内核线性映射常量，来自 .ko/内核）
```
PAGE_OFFSET = 0x60000000     DDR0 线性映射起点（1 GB）
DDR1_BASE   = 0x80000000     第二片 DRAM 物理基址；其线性映射 VA = 0xA0000000
VA→PA:  VA < 0xA0000000 → PA = VA - 0x60000000 ;  VA >= 0xA0000000 → PA = VA - 0x20000000
PA→VA:  PA < 0x80000000 → VA = PA + 0x60000000 ;  PA >= 0x80000000 → VA = PA + 0x20000000
```
数值相同、含义不同的区间对照（**用错就进物理空洞**）：
```
0x00000000-0x3FFFFFFF  = DDR0 物理（含保留洞）        不是 VA
0x40000000-0x5FFFFFFF  = 主系统物理空洞                不是 VA
0x60000000-0x9FFFFFFF  = 物理空洞                     = DDR0 线性映射
0xA0000000-0xAFFFFFFF  = 无 DRAM                      = DDR1 线性映射
```
- **`0x635C6000` 不是 ARM 物理地址**：作为 PA 落在空洞里 ⇒ `db 0x635C6000` 可能锁总线；作为 **VA** 它等于 **PA `0x035C6000`**（在保留 RAM 窗内）。DSP 侧地址（入口 `0x635C6044`）是 DSP 自己 MMU 的编号，**不能直接喂给 `db`**。⇒ 想读那一片就写 `db 0x035C6000`。
- `logaddr` 的表：**109 个 SID / 417 个区域，全部落在 PA `0x030850d8`–`0x034bd190`**，与我独立算出的 LOGB(`0x03085000`,`len 0x478000`)/PRTB(`0x034FD000`) 吻合 ⇒ 两条路互证。

## 3. `dk <base> <size> <file>` 落盘
路径**任意可写路径**（直接进 `open`），flags `0x642`，大小无上限，只受命令行缓冲 `0x80` 与 PA 有效性限制。

## 4. ★我自己推出来的结论：读 OTP/SKD 窗是"出厂固件已经在做的事"
`notes/skd-key-source.md` 里 `SKData_Init` 每次更新都会 `open("/dev/mem") → mmap(0x400 @ 0xFFFF5000)` 和 `mmap(0x20 @ 0xF340F000)`。
⇒ **PA `0xF340F000` 与 `0xFFFF5000` 在真机上是可映射、可读的窗口**（不是空洞）；用 `dk 0xF340F000 32 /tmp/skd.bin` 读它，与固件自己做的读等价 ⇒ **风险 R1，而不是"可能锁总线"**。仍按只读、只读这两处、不写来做。

## 5. 上机安全规则（据此写死）
1. 只读这几个地址：`0xF340F000`(32B)、`0xFFFF5000`(0x400)、`0x02E80000`(Backup RAM 头部若干 KB)、`0x03085000`(LOGB)、`0x034FD000`(PRTB)。
2. 不读 `0x40000000–0x7FFFFFFF` 当 PA 用；不读没验证过的设备区。
3. `mb/mw/ml/mf/mu`（写内存）本轮一律不用，除非另有明确必要性并先只写日志区。
4. 会话唯一 ⇒ 上机期间不让别人连 23。
